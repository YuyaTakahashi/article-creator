# 編集差分からの学習ログ

公開された記事は、AIの初稿に人が手を入れたもの。その差分には「いまの執筆ルールで防げていない弱点」が現れる。ここは、その弱点を言葉にして積んでおく置き場。

| ファイル | 中身 |
|---|---|
| `observations.md` | 週次バッチが積む観測ログ。記事ごとに「何が直されたか」と「既存ルールで防げたはずか」を記録する |
| `proposal-{日付}.md` | 未反映の観測が3本たまったときに出る執筆ルールの改訂案 |

## 回し方

```bash
bash scripts/weekly-learn-batch.sh        # 差分収集 → 分類 → 観測ログに追記（3本たまれば改訂案も）
python3 scripts/collect_edit_gaps.py      # 差分収集だけ手で回す
```

改訂案を採用したら、次の順に進める。

1. `prompts/` の該当箇所を書き換える
2. `python3 scripts/recipe_version.py bump --note "改訂の要約"`
3. `observations.md` の該当記事の `— 未反映` を `— 反映済み(vN)` に書き換える
4. 旧版になった記事は `@用語くん 古い記事教えて` で一覧でき、`@用語くん ◯◯ を最新版で作り直して` で作り直せる

ここでループが閉じる。**このバッチはプロンプトを自動では書き換えない。** 言い回しの最終判断は人がする。
