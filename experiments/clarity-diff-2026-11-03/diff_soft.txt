  - 正解を1つに決めて教える方法との違いは、正解以外の候補にどれくらい近いかという情報も残せることである。

  + # ソフト・ラベリングとは
  + **ソフト・ラベリングは、AIに「正解」だけでなく、「ほかの答えの可能性」も教える方法です。
  + **。
  + たとえば、手書きの「2」をAIに覚えさせるとき、ふつうは「正解は2」とだけ教えます。
  + ソフト・ラベリングでは、次のように教えます。
  + - 「2」の可能性：90％。
  + - 「3」の可能性：8％。
  + - 「7」の可能性：2％。
  + ※数字は説明用の例です。
  + こうすると、AIは「これは2だ」ということに加え、**「7よりは3に似ている」**という情報も学べます。
  + このように、候補ごとに確からしさを割り振った答えを「ソフトラベル」と呼びます。
  + ## 大きなAIから、小さなAIへ教える
  + ソフトラベルの代表的な使い方が、大きなAIの知識を小さなAIに移す「知識蒸留」です。
  + 流れは次のとおりです。
  + 1. 学習済みの大きなAIに、画像などを見せる。
  + 2. 大きなAIが、答えの候補ごとに確率を出す。
  + 3. 小さなAIが、その確率に近い答えを出せるように学ぶ。
  + いわば、大きなAIが先生、小さなAIが生徒になる仕組みです。
  + 先生は正解だけでなく、「ほかの候補をどのくらい考えたか」も伝えます。
  + ## 小さな可能性を学びやすくする「温度」
  + 大きなAIが自信を持っていると、「2」がほぼ100％になり、ほかの数字の確率が極端に小さくなることがあります。
  + これでは、正解以外の候補の違いを小さなAIが学びにくくなります。
  + そこで使うのが、**確率の偏りを調整する「温度」**という設定です。
  + 熱さのことではありません。
  + 温度を上げると、最有力の候補に集中していた確率が、ほかの候補にも広がります。
  + その結果、「この2は、7より3に似ている」といった違いを学びやすくなります。
  + ## どんな効果があるのか
  + 2015年にHintonらが発表した研究では、手書き数字を読むAIで、次のような結果が報告されました。
  + | AI | テストで読み間違えた数 |。
  + |---|---:|。
  + | 大きなAI | 67個 |。
  + | 小さなAI | 146個 |。
  + | 大きなAIの確率も使って学んだ小さなAI | 74個 |。
  + この実験では、**小さなAIでも、大きなAIに近い成績を出せました。
  + **。
  + 文章を扱うAIを小型化した「DistilBERT」も、ソフトラベルを活用した例です。
  + 研究では、元のAIと比べて、モデルの大きさを40％減らし、言語理解の性能を97％保ちながら、60％高速になったと報告されています。
  + ただし、どのAIでも同じ効果が出るわけではありません。
  + ## 人の判断からも作れる
  + ソフトラベルは、大きなAIの答えからだけでなく、人の判断からも作れます。
  + たとえば、ある文章について10人が判断し、7人が「喜び」、3人が「驚き」に分類したなら、次のようなラベルにできます。
  + - 喜び：70％。
  + - 驚き：30％。
  + 1つの正解に決めるだけでは失われる、判断の迷いや意見の違いも、学習に生かせます。
  + ## まとめ
  + ソフト・ラベリングは、**「正解はこれ」とだけ教えるのではなく、「ほかの答えにも、これくらい可能性がある」と教える方法**です。
  + 正解以外の候補にも含まれる情報を使うことで、AIの学習を助けたり、大きなAIの能力を小さなAIへ移したりできます。
