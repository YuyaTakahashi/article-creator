  - マウスは、画面上の位置を示す印を動かすための道具である。
  - 利用者はマウスでその印を動かし、ファイルをつかんだまま移動先へ運ぶ。
  - この、つかんだまま動かす操作をドラッグという。
  - このファイル移動は、GUIの中でも「直接操作」にあたる。
  - 直接操作とは、画面に見えるものに少しずつ働きかけ、結果をすぐに画面で確認でき、やり直せる操作のことである。
  - GUI全体を指す言葉ではなく、GUIで使われる操作の一つの型である。

  + ## GUIとは
  + GUI（グラフィカル・ユーザー・インターフェース）とは、**画面に表示された絵やボタン、メニューなどを選んで、コンピュータを操作する仕組み**です。
  + パソコンではマウスを、スマートフォンでは指を使います。
  + たとえば、ファイルを別のフォルダに移すとき、文字で命令を入力しなくても、画面上のファイルをマウスでつかんで移動できます。
  + ## ファイルをつかんで動かす操作
  + ファイルを移すときは、次のように操作します。
  + 1. 移したいファイルと、移動先のフォルダを画面上で見つけます。
  + 2. ファイルにマウスの矢印を合わせ、ボタンを押したまま動かします。
  + 3. 移動先のフォルダでボタンを離します。
  + ボタンを押したまま動かすことを「ドラッグ」、移動先で離すことを「ドロップ」といいます。
  + このように、**画面に見えているものに働きかけ、その結果をすぐに確認できる操作**を「直接操作」といいます。
  + 直接操作では、操作を少しずつ進めたり、間違えたときに元に戻したりできることも大切です。
  + GUIは画面を使った操作の仕組み全体を指し、直接操作はその中の一つの操作方法です。
  + ## GUIはどのように広まったのか
  + GUIは、多くの研究や製品を通じて発展しました。
  + - **1960年代**：ダグラス・エンゲルバートのチームが、マウスなどを使う操作方法を研究しました。
  + - **1973年**：ゼロックスの研究所で、GUIの発展につながるコンピュータ「Alto」が登場しました。
  + - **1984年**：Appleが「Macintosh」を発売し、マウスで画面を操作する方法が広まりました。
  + - **1990年以降**：「Windows 3.0」などの普及により、GUIがパソコンで広く使われるようになりました。
  + ## GUIが使いやすい理由
  + GUIの利点は、**操作に必要な命令を覚える負担が少ないこと**です。
  + 文字で命令を入力する方式では、どんな命令を使うのか、その書き方も知っておく必要があります。
  + GUIなら、画面にあるファイルやボタンを見つけて操作できます。
  + メニューも同じです。
  + 使える機能が一覧で表示されるので、命令を自分で思い出す代わりに、その中から選べます。
  + ## スマートフォンの写真操作も一例
  + スマートフォンで写真を見るとき、写真の上に置いた2本の指を広げると拡大し、すぼめると縮小します。
  + これも直接操作の一つです。
  + この操作を使いやすくするには、次のことが大切です。
  + - 操作する写真が画面に見えていること。
  + - 指の動きに合わせて、写真の大きさがすぐに変わること。
  + - 大きくしすぎても、簡単に小さく戻せること。
  + つまり、GUIでは、**何を操作しているのか、操作するとどう変わるのかが、目で見てわかること**が重要です。
