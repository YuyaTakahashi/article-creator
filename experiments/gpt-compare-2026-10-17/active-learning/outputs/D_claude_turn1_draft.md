0. 最小限の説明
学習中のモデルが、人に正解を付けてもらうデータを自ら選ぶ学習法 [C01,C02]
1. 導入と定義
アクティブラーニング（active learning）は機械学習の一分野であり、統計の分野では「クエリ学習」や「最適実験計画」と呼ぶこともある。この手法の中心には、ひとつの考えがある。学習アルゴリズムが自分の学ぶデータを選べるなら、より少ない教師ラベル（人がデータに付ける正解の印）で高い精度に届く、という考えである。[C01,C49]
分類を行う機械学習のモデルは、正解の付いた例をたくさん見て学ぶ。教師あり学習がうまく動くには、数百から数千のラベル付き事例が必要になることが多い。ところが多くの現場では、ラベルの付いていないデータは大量に手に入るのに、正解を付ける作業のほうが難しく、時間がかかり、高くつく。アクティブラーニングが役に立つのは、まさにこの場面である。[C03,C04]
ベースにある通常の教師あり学習（受動的学習）では、学習データは与えられるか無作為に引くかで決まり、モデルはどのデータを学ぶかを選ばない。アクティブラーニングでは、学習中のモデルがラベルの付いていないデータを示して「これの正解を教えてほしい」と質問を出す。そして、人間の注釈者など答えを返す相手（オラクル）がそのデータにラベルを付ける。[C02,C13,C37]
いま一般的な形であるプールベースのサンプリングでは、少数のラベル付きデータ L と、大量のラベルなしデータ U を用意する。モデルは U というたまり場（プール）の中から、質問するデータを選ぶ。選び方の代表は不確実性サンプリングであり、モデルは「どちらのラベルを付けるべきか最も分からない事例」を質問に選ぶ。おそらく最も単純で、よく使う方法である。[C09,C10]
「最も分からない」の測り方は、分類するクラスの数で変わる。2つのクラスに分ける場合、モデルが「該当である」と見積もった確率が0.5に最も近い事例を選ぶ。3つ以上のクラスに分ける場合は、最も確からしいラベルの確率が低い事例を選ぶ方法、1位と2位の確率の差が小さい事例を選ぶ方法（マージンサンプリング）、予測の散らばり具合を表すエントロピーを使う方法がある。[C11,C12]
Lewis と Gale が示した手順は、次の流れを繰り返す。まず初期の分類器を作る。続いて、教師が答えてくれる間、現在の分類器をラベルなしの各事例に当て、どのクラスに属するかが最も不確かな b 件を見つける。そのb件に教師がラベルを付け、ラベル付きの全事例で新しい分類器を学習し直す。[C22]
この記事では、Lewis と Gale の実験を通し例として使う。課題は、AP通信の見出し319,463件から、bonds（債券）の話題に当たる見出しを見分ける分類器を作ることである。該当する見出しは学習用データの中に470件、割合にして0.15%しかない。人が30万件すべてに正解を付けるのは現実的でなく、しかも無作為に数百件を選んで答えても、該当する見出しがほとんど含まれない。[C21,C25,C26]
そこで学習中の分類器は、該当である確率を0.5付近と見積もった見出しを選ぶ。人が選ばれた4件に答え、その答えを足して分類器を学習し直す。著者らはこれを249回繰り返し、人が答えた件数は合計999件になった。論文は、多くのカテゴリで、無作為に選ぶなら10万件以上答えてやっと届く性能に、不確実性サンプリングは1000件未満で届いたと報告している。[C11,C22,C27,C28]
なお、教育分野にも同じ名前の active learning がある。教育分野の active learning は、学生が何かを行い、自分が行っていることについて考える指導方略を指し、受け身で講義を聞くことの対義にあたる。Settles は、機械学習のアクティブラーニングがこの指導法と精神的には通じるものの、混同してはならないと書いている。学ぶのは人間であり、機械がデータを選ぶ話ではない。[C07,C08]
2. 生まれた背景（語源・提唱者）
研究者が最初期に調べた場面のひとつは、Angluin が1988年に示したメンバーシップクエリ学習である。この場面では、学習側が入力の取りうる範囲のどの事例についてもラベルを要求でき、典型的には事例を自分で新しく作り出して尋ねる。[C15]
ところが、この方法は人に答えさせると問題を起こした。Lang と Baum は1992年、手書き文字を分類するニューラルネットを学習させる際に、メンバーシップクエリへの答えを人に返させた。学習側が生成した質問画像の多くは認識できる記号を含まず、自然な意味を持たない人工的な合成文字になっていた。[C16]
この限界に対処するため、研究者はストリームベースとプールベースの場面を提案した。ストリームベースの選択的サンプリング（Cohn ら、1990年・1994年）では、ラベルなしの事例を実際のデータから1件ずつ取り出し、学習側がそれを質問するか捨てるかを決める。プールベースでは、学習側が手元の集合全体を評価して順位を付け、そのうえで最良の質問を選ぶ。[C17,C18,C19]
プールベースのサンプリングと不確実性サンプリングを提案したのは、AT&T ベル研究所（ニュージャージー州マレーヒル）の David D. Lewis と William A. Gale である。2人は1994年の SIGIR で論文「A Sequential Algorithm for Training Text Classifiers」を発表した。[C09,C10,C20,C50]
2人の出発点にあった困りごとは、経済的にラベル付けできる量より多くのテキストがあることだった。その場合、ラベルを付けるデータを選ばなければならないが、無作為抽出は通常うまくいかない。1000件に1件しか該当しない状況で500件しかラベル付けできなければ、無作為な標本は通常500件すべてが非該当になる。それでは、該当と非該当を見分ける学習ができない。[C21]
提唱の根拠になった実験では、1988年から1993年初頭までのAP通信の見出し371,454件を使った。著者らはこれを、学習用319,463件とテスト用51,991件に無作為に分けた。カテゴリは、出現頻度が低いながらも学習用とテスト用の両方に該当例がそれなりにある10種類を選んだ。各試行では、該当する見出し3件から初期の分類器を作り、4件ずつの不確実性サンプリングを249回行った。その結果、不確実性サンプリングは、一定の性能に届くまでに人手で分類する学習データの量を最大で500分の1に減らした。[C20,C25,C26,C27,C28]
その後、Burr Settles は2009年に University of Wisconsin–Madison の Computer Sciences Technical Report 1648 として「Active Learning Literature Survey」を出し、この分野で初の大規模なサーベイだと書いた。Settles によれば、応用を扱う論文ではプールベースの場面がストリームベースよりずっとよく見られる。[C48,C51,C52]
3. 効果・現れ方
効き目の大きさは、同じ精度に届くまでに人が答えた件数で比べる。Settles のサーベイは、2つのガウス分布から作った400件の二次元データで違いを示している。無作為に選んだ30件で学習したロジスティック回帰の正解率は70%だったが、不確実性サンプリングで選んだ30件で学習すると90%になった。[C13]
実データでも同じ傾向が出ている。20 Newsgroups の野球とホッケーの文書2,000件を見分ける課題では、30件を新たにラベル付けした時点の正解率が、不確実性サンプリングで81%、無作為で73%だった。Lewis と Gale の実験では、1000件を無作為に選んで学習した分類器の性能は、不確実性サンプリングで選んだ1000件未満の分類器より大きく劣った。ある場合には、同じ性能に届くのに、無作為だと500倍の件数が要った。[C14,C28]
ただし、Lewis と Gale の結果には意外な点や限界もある。10カテゴリのうち6つでは、999件の不確実性標本で学習した分類器の平均F値（分類の当たり具合を表す指標）が、319,463件すべてで学習した分類器を上回った。著者らはこれを、自分たちの学習方法が大きな学習データを活かせていない兆候とみなし、特徴選択（分類に使う手がかりの選び方）を最も疑わしい原因に挙げた。また tickertalk というカテゴリでは、どの方法もうまくいかなかった。最初の3件の選び方が悪いと初期の分類器が効かず、追加の該当事例が見つかるまでにかなりの遅れが出て、最終的な分類器の質にもばらつきが残った。[C29,C30,C31]
反証も報告されている。Schein と Ungar は2007年、同じ種類のモデル（ロジスティック回帰）を使った場合でも、アクティブラーニングが受動的学習より多くのラベル付き事例を必要とすることがあると示した。Guo と Schuurmans は2008年、既成の質問戦略をまとめて何件も選ぶ場面（バッチモード）で目先の基準だけで使うと、しばしば無作為抽出よりずっと悪くなることを見つけた。[C33,C34]
効き方は条件によっても変わる。注釈のコストが事例ごとに大きく変わる領域では、コストを無視するアクティブラーニングが無作為選択と変わらない結果になることがある。Baldridge と Palmer は2009年、注釈者の熟練度によって効き方が変わることを報告した。領域の専門家はアクティブラーニングでうまく活き、初心者は受動的学習のほうが向いていた。[C35,C37]
実務家の受け止め方にも幅がある。Tomanek と Olsson の2009年の調査では、大規模な注釈プロジェクトでアクティブラーニングを使った研究者の91%が、期待は完全または部分的に満たされたと答えた。一方で回答者の20%は、自分の場面でうまくいくと確信できないという理由で、使わないことを選んだ。[C36]
5. 実務でどう使われるか
アクティブラーニングが効くのは、正解を付ける作業が重い工程である。音声の書き起こしでは、単語の単位で注釈を付ける作業に実際の音声の10倍（1分の音声に10分）、音素（音の最小単位）の単位では400倍（1分に7時間近く）かかる。情報抽出（文章から人名や組織名、それらの関係を拾い出す作業）では、簡単なニュース記事でも該当箇所を見つけるのに30分以上かかることがあり、遺伝子や疾患の注釈には博士号を持つ生物学者が必要になる。[C05,C06]
実際のサービスの例として、Amazon SageMaker Ground Truth の自動データラベリングがある。この機能はまず入力データから無作為に標本を選んで人の作業者に回し、返ってきたラベルから学習用と検証用のデータを作って、自動でラベルを付けるモデルを学習・検証する。続いて、検証データへの推論で出た信頼度と品質の指標から信頼度の閾値を決め、閾値を満たしたデータは自動でラベル付け済みとみなす。信頼度の低いデータだけを人に回し、そのラベルでモデルを更新する。この繰り返しは、データセットがすべてラベル付けされるか、人の注釈予算に達するなどの停止条件を満たすまで続く。工程は通し例と同じだが、信頼度の高い件を機械が自動でラベル付けする点が足されている。[C43,C44,C45]
この機能では、成果物としてラベル付きのデータセットが残り、人の作業者と自動ラベリング用のモデルが分担してそれを作る。画像分類とテキスト分類では、自動で付けたラベルの正確さが人の付けるラベルに対して95%以上になる信頼度の水準を使う。AWS は、この機能が数千件規模のデータに向くとしており、許容する最小の件数は1,250件だが、5,000件以上を強く推奨している。[C46,C47]
実務で失敗しやすい点もいくつかある。第一に、最初の分類器の質である。初期の分類器が無いと、出現頻度の低いクラスの事例に偶然ぶつかるまで長く無作為抽出が続きかねず、最初の数件の選び方が悪いと立ち上がりが遅れる。第二に、1回に選ぶ件数 b である。理想は1件だが、事例を採点して選ぶ処理が高くつく場合は大きい値が適切なことがある。ただし前述のとおり、まとめて選ぶ場面では無作為より悪くなることも多い。[C23,C24,C31,C34]
第三に、コストと人の質である。注釈のコストは事例に内在するとは限らず、誰が注釈するかで変わる。人の付けるラベルの質も高いとは限らない。ある事例は人にも機械にも本質的に難しく、人は時間とともに気が散ったり疲れたりして、注釈の質にばらつきが出る。[C38,C42]
第四に、止めどきとデータの使い回しである。Settles は、実用的な応用での本当の止めどきは、学習側が自分で決める閾値よりずっと手前に来る経済的その他の外部要因で決まる、と自身の経験から書いている。また、アクティブラーニングと協調して作った学習データは、質問を選んだモデルの種類に結びついた偏った分布になる。技術が進んでモデルの種類を変えると、そのデータは新しいモデルに同じようには役立たなくなりうる。[C32,C39]
関連用語
教師あり学習（受動的学習）は、学習データが与えられるか無作為に引かれ、モデルがどのデータを学ぶかを選ばない学習の形である。アクティブラーニングとの違いは、モデルが質問するデータを選ぶかどうかにある。[C13,C28]
半教師あり学習は、ラベルなしデータを活かす点でアクティブラーニングと同じ問題に取り組むが、方向が逆である。半教師あり学習は学習側が知っていると思う部分を活用し、アクティブラーニングは未知の部分を探りにいく。代表的な自己訓練では、モデルが最も自信のあるラベルなし事例を予測ラベルごと学習データに加え、人には聞かない。不確実性サンプリングは逆に、最も自信のない事例を人への質問に選ぶ。[C40,C41]
メンバーシップクエリ学習は、学習側が事例を新しく作り出してラベルを尋ねる、アクティブラーニングの初期の場面である。手元のデータから選ぶ現在の一般的な形とは異なり、人が答えられない質問を生むことがある。[C15,C16]
不確実性サンプリングは、アクティブラーニングで「どれを質問するか」を決める方法のひとつであり、学習側がラベルの付け方を最も分からない事例を選ぶ。アクティブラーニングのほうが、より広い概念にあたる。[C10]
ストリームベースの選択的サンプリングは、ラベルなし事例を1件ずつ取り出し、そのつど質問するか捨てるかを決める場面である。プールベースが集合全体に順位を付けてから選ぶのに対し、こちらは順に走査して1件ずつ判断する。[C18,C19]
教育分野のアクティブラーニングは、学生が何かを行い、行っていることについて考える指導方略である。名前は同じだが、学ぶのは人間であり、本記事の用語とは別物にあたる。[C07,C08]
