# アクティブラーニング

## 最小限の説明

学習中のモデルが、人に正解を付けてもらうデータを自ら選ぶ学習の手法

-- wp分割ライン--

アクティブラーニング（active learning）とは、学習中のモデルが次に正解を付けてもらうデータを自分で選ぶことで、少ない正解の数で高い精度に届くことを目指す機械学習の手法である。モデルはデータから判断の規則を学ぶプログラムを指し、正解（ラベル）は人がデータ1件ずつに付ける「これは何か」の印を指す。統計の分野では、同じ手法を「クエリ学習」や「最適実験計画」と呼ぶこともある。

たとえば、ニュースの見出し約32万件から、債券の話題だけを拾い出す分類器（データを「該当」と「非該当」に振り分けるモデル）を作る場面を考える。人が全件に正解を付けるのは現実的でなく、しかも債券の見出しは470件、全体の約0.15%しかない。アクティブラーニングでは、学習中の分類器が「債券の話題かどうか五分五分で迷う見出し」を選び、人はその数件にだけ答える。

通常の教師あり学習では、学習に使うデータを人が与えるか無作為に選ぶかで決め、モデルはデータを選ばない。アクティブラーニングは、どのデータに正解を付けるかという選択をモデル側に持たせた点で異なる。

## 迷った見出しだけを人に聞く

冒頭の債券の例で、分類器が人に聞く見出しを選び、答えを取り込んで精度を上げていく手順は次のとおりである。

* 最初の分類器を作る：債券の見出し3件から、まだ粗い分類器を作る。
* 迷う見出しを選ぶ：分類器を正解の付いていない見出しすべてに当て、債券である確率を0.5付近と見積もった見出しを4件選ぶ。
* 人が答える：選んだ4件に、人が「債券の話題か、そうでないか」の正解を付ける。
* 学習し直す：それまでに正解の付いた見出しすべてで、分類器を作り直す。

この実験では4件ずつの選択を249回くり返し、人が答えた見出しは最初の3件と合わせて999件になった。手元に少数の正解付きデータと大量の正解なしデータを置き、その「たまり（プール）」から聞くデータを選ぶこの形を、プールベースと呼ぶ。

最も判断に迷うデータを選ぶやり方は不確実性サンプリングと呼び、アクティブラーニングで「どれを聞くか」を決める方法のうち、おそらく最も単純でよく使う方法である。3つ以上のグループに振り分ける場合は、1位と2位の候補の確率の差が小さいデータを選ぶ方法や、予測の散らばり具合で迷いを測る方法がある。

半教師あり学習も正解なしデータを活かすが、向きが逆である。代表的な自己訓練では、モデルが最も自信のあるデータに自分で正解を付けて取り込み、人には聞かない。アクティブラーニングは、モデルが最も自信のないデータを人に聞く。また教育分野にも同名の active learning があり、こちらは学生が何かを行い、行っていることについて考える指導法を指す。学ぶのは人間であり、機械がデータを選ぶ話とは別物である。

## 語源・提唱者

学習側が自分で尋ねるデータを決める研究は、Angluin¥アングルイン¥ 氏が1988年に示したメンバーシップクエリ学習にさかのぼる。この形では、学習側が手元にないデータを自分で新しく作り出し、その正解を尋ねる。ところが1992年に手書き文字の分類で人に答えさせた研究では、学習側が作った質問画像の多くが、どの文字とも読めない合成の図形になった。人が答えられないこの限界に対処するため、研究者は実際のデータの中から選んで尋ねる形を提案した。

AT&T ベル研究所の David¥デイビッド¥ D.¥ディー¥ Lewis¥ルイス¥ と William¥ウィリアム¥ A.¥エー¥ Gale¥ゲイル¥ は1994年、プールから選ぶ形と、その選び方である不確実性サンプリングを提案した。2人が問題にしたのは、経済的に正解を付けられる量よりテキストのほうが多く、無作為に選ぶ方法が通常うまくいかない点である。1000件に1件しか該当しない状況で500件しか正解を付けられなければ、無作為に選んだ500件はふつうすべて非該当になり、該当と非該当を見分ける学習ができない。

ルイス氏とゲイル氏は、1988年から1993年初頭までのAP通信（アメリカの通信社）の見出し371,454件を学習用とテスト用に分け、債券など出現頻度の低い10種類の話題で手順を試した。その結果、一定の性能に届くまでに人が正解を付ける量を、最大で500分の1に減らした。

2009年にこの分野で初めての大規模な文献調査をまとめた Burr¥バー¥ Settles¥セトルズ¥ 氏によれば、応用を扱う論文では、プールから選ぶ形を使うもののほうが、データを1件ずつ取り出してそのつど聞くかどうかを決める形よりずっと多い。

## 答える件数が大きく減る

無作為に選ぶ方法では、債券の例を含む10種類の話題の多くで、10万件以上の見出しに答えてやっと届く性能があった。迷う見出しを選ぶ方法は、同じ性能に1000件未満で届いた。同じ1000件でも、無作為に選んで学習した分類器の性能は大きく劣った。

単純な課題でも差は出る。英語の掲示板の投稿から野球とホッケーの投稿2,000件を見分ける課題では、新たに30件へ正解を付けた時点の正解率が、迷う投稿を選んだ場合に81%、無作為に選んだ場合に73%だった。

## 無作為より劣る場面がある

セトルズ氏の文献調査は、効果が逆向きに出た報告も紹介している。同じ種類のモデルを使っても、アクティブラーニングのほうが無作為に選ぶ場合より多くの正解を必要とした例がある。一度に何件もまとめて選ぶ場面で既成の選び方を目先の基準だけで使うと、無作為に選ぶよりずっと悪くなることが多い。ルイス氏らの実験でも、10種類の話題のうち1つでは、どの方法もうまくいかなかった。

効き方は、正解を付ける側の条件でも変わる。正解付けの手間がデータごとに大きく違う領域では、手間を考えずに選ぶと、無作為に選ぶ場合と結果が変わらないことがある。別の研究では、その分野の専門家が答える場合はアクティブラーニングがうまく働き、初心者が答える場合は無作為に選ぶほうが向いていた。

集めたデータにも癖が残る。アクティブラーニングで集めたデータは、質問を選んだモデルの好みに偏っている。新しい種類のモデルに乗り換えると、そのデータは新しいモデルに同じようには役立たない可能性がある。

それでも、2009年の調査では、大規模な正解付けの作業でアクティブラーニングを使った研究者の91%が、期待が完全または部分的に満たされたと答えた。一方で回答者の20%は、自分の場面でうまくいくと確信できないという理由で、使わないことを選んだ。

## 正解付けを機械と人で分け合う

アクティブラーニングが役立つのは、正解を付ける作業が重い場面である。音声の書き起こしでは、単語ごとに正解を付ける作業に実際の音声の10倍（1分の音声に10分）かかる。文章から人名や組織名を拾い出す作業では、短いニュース記事でも30分以上かかることがあり、遺伝子や病気の名前を拾うには博士号を持つ生物学者が必要になる。

Amazon のクラウドサービス AWS は、画像やテキストに正解を付ける作業を支援するサービス「SageMaker Ground Truth」に、自動データラベリングという機能を用意している。この機能は、通し例の手順に「自信のある分は機械が正解を付ける」工程を足した形で動く。

* 無作為に人へ回す：最初に入力データから無作為に選んだ分を人の作業者に回し、返ってきた正解で、自動で正解を付けるモデルを学習・検証する。
* 自信のある分は機械が付ける：検証の結果から信頼度の基準線を決め、基準を満たすデータには機械が正解を付ける。
* 自信のない分だけ人に聞く：信頼度の低いデータを人に回し、その正解でモデルを更新する。

AWS は、全データに正解が付くか、人の作業予算に達するなどの条件を満たした時点でくり返しを止める。画像とテキストの分類では、機械の付けた正解が、人が付ける正解と比べて95%以上正しくなる信頼度を基準線に使う。対象は数千件規模のデータであり、最低1,250件、推奨は5,000件以上である。

運用でつまずきやすいのは、出だしと人の側である。ルイス氏らの実験では、最初の3件が話題をうまく代表していないと分類器が働かず、次の該当データが見つかるまでにかなりの遅れが出た。正解付けの手間は答える人によって変わり、人は時間とともに気が散ったり疲れたりして、正解の質にばらつきを生む。セトルズ氏は自身の経験から、実務で作業を止める時期は、モデルが決める基準よりずっと手前で予算などの外部の事情が決めると書いている。
