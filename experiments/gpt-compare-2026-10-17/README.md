# ChatGPT比較実験（2026-10-17）

## 目的

article-creator（v19）の文章品質の課題が「モデル」と「ルール・工程」のどちらから来ているかを切り分ける。

## 比べる4本（用語ごと）

| 記号 | 作り方 | ファイル |
|---|---|---|
| A | 今のarticle-creator（Critic・照合込み）の初稿 | outputs/A_claude_pipeline.md（作成済み） |
| B | ChatGPT＋今のプロンプト（01の初稿→02の整形） | outputs/B_gpt_full.md |
| C | ChatGPT＋最小指示（台帳・見出し・わかりやすさだけ） | outputs/C_gpt_minimal.md |
| D | Claude（claude.ai）＋Bと同じプロンプト | outputs/D_claude_full.md |
| 正解 | 公開版 | outputs/REF_published.md（作成済み） |

リサーチ（出典台帳・成立条件メモ）は全員に同じものを渡すので、差は「書く力」と「指示」だけになる。

- A vs D：Critic・照合の工程が効いているか
- B vs D：同じ指示でのモデルの差
- B vs C：ルールの積み上げが品質を上げているか下げているか

## 実行手順

1. ChatGPTは「一時チャット」で開き、メモリとカスタム指示が効かない状態にする。Web検索はオフにする。使ったモデル名を控える。
2. B：新しいチャットで `1_full_turn1.txt` の全文を貼って送る。返ってきたら、同じチャットで `1_full_turn2.txt` の全文を貼って送る。2回目の出力を `outputs/B_gpt_full.md` に保存する。
3. C：新しいチャットで `2_minimal.txt` の全文を貼って送り、出力を `outputs/C_gpt_minimal.md` に保存する。
4. D：claude.ai をシークレットチャット（個人設定が効かない状態）で開き、Bと同じ2回の手順で `outputs/D_claude_full.md` を作る。Dは省略してもよいが、その場合はA vs Bの差がモデルか工程か区別できない。
5. 3用語すべてで、同じモデル・同じ手順で行う。

## 評価

保存が終わったら、Claudeに「gpt-compare をブラインド化して」と頼む。A〜Dの記号を伏せて並べ替えたものを作るので、それを読んで次の2つを付ける。

- この版を公開まで持っていくなら、修正レベルは1〜3のどれか（article-edit-retro と同じ物差し）
- 4本のうち、いちばん読みやすいのはどれか

台帳にない事実を書いていないか（B・C・Dの事実の混入）は、Claudeが台帳と照合して別に出す。

## 限界

- 3本とも AI・機械学習系の用語なので、人名や心理効果が中心の用語での傾向はこの実験ではわからない。
- 1回ずつの生成なので、出力のぶれと差を区別できない。差が小さいときは結論にしない。
